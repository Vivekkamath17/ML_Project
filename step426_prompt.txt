## STEP 1: Loader, metrics and MLflow setup
**data.py**: one function `load_split(split, k=3, min_week=2, drop_never_active=True, drop_proxy=False, allow_test=False)` returning X (only the sanctioned features), y, and a metadata frame (learner key, week, module, split, flags needed for robustness slices). All filtering (enrolled, non-censored, min_week, flags) happens here and nowhere else. Print row counts, learner counts and the positive rate for each split.

**metrics.py**: one function computing, for given y_true, y_score and a threshold:
- ROC-AUC, PR-AUC (average precision), base rate, PR-AUC as a multiple of the base rate
- precision, recall, F1, MCC, confusion matrix (TP, FP, FN, TN)
- Brier score
- precision@top-5%, recall@top-5%, precision@top-10%, recall@top-10%, lift@top-10%
- **Bootstrap 95% CIs resampled BY LEARNER** (not by row, since a learner's weekly rows are correlated), 500 resamples by default (configurable)

**tests/test_models.py**: unit-test the metrics against scikit-learn on toy data, test that the loader filters are correct (no censored rows, no week < min_week, no never-active rows when excluded), test that the test-split guard raises, and test that no non-sanctioned column reaches X.
